# Oi tag page

What an Oi card's NFC tag and QR code carry: `https://c.oistudios.com.au/<CODE>` (Nick, 27 Nov 2026), short so the QR code on a card stays small. Until that address answers it is `https://oi-studios.github.io/oi/<CODE>`, the same page. The page asks the Oi status sheet's script for that card as data (`?format=json`, fetched without cookies) and draws the status itself. The address with no code lists every card. `<CODE>/log` opens the same page at its log buttons (the first tags carried it). Logging goes through the script's log action with the page's own key (public by nature; every change is in the Log with source "Card page"), so it needs no Google sign-in and answers at once, refusals included. Add `?dry=1` to test without saving. The Google Form stays as a fallback link.

Why it isn't the script's own page: in iPhone Safari that page showed Google's "Sorry, unable to open the file at present" when reached from a tag. This page never touches a Google sign-in. The Log buttons open the Oi Card Log form, which still needs an Oi Google account.

Where it lives (27 Nov 2026): the public repo `Oi-Studios/oi`, published with GitHub Pages at `https://oi-studios.github.io/oi/`. It moved there from Nick's own GitHub account; `osimages.github.io/oi/...` is now a small repo of redirects to the new address, so the first test label and tag keep working. `c.oistudios.com.au` needs one DNS record at GoDaddy, where `oistudios.com.au` is hosted: `c`, CNAME, `oi-studios.github.io`. Then add a `CNAME` file holding `c.oistudios.com.au` to this folder and publish: GitHub serves the pages there and sends `oi-studios.github.io/oi/...` on to it. Only then change the Tag link formulas (the status sheet's Cards column K and the register's column E) and print labels or write tags; lock a tag once it carries the final address.

Built from `redirect/` in the Oi Asset Tracking repo (`Oi-Studios/oi-asset-tracking`) with `sh make.sh <codes>`, then published with `git subtree push --prefix=redirect https://github.com/Oi-Studios/oi.git main` from the repo's top folder. A card added to the register works through `404.html` before it has a folder of its own.
